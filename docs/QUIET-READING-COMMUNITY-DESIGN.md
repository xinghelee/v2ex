# Quiet Reading Community / 静读社区

第二轮方向参考成熟阅读产品的舒适感，但不复制其书城结构或品牌表达。视觉重点从“展示设计感”转为“让用户愿意长时间停留”。

## 设计原则

- 大面积低对比暖灰背景，正文使用柔和纸白表面。
- 仅使用深森林绿和阅读绿作为主要信号色。
- 主要容器承担完整语义，普通话题和回复不重复套卡片。
- 导航、操作和元数据在阅读时主动后退。

## V2EX 自有表达

- **社区在读**：把当前高活跃讨论组织成阅读入口，而不是传统运营 Banner。
- **讨论进度**：用轻量进度线帮助用户恢复长帖阅读位置。
- **节点书架**：以个人关注节点为“书脊”，下方仍保留完整可预测的目录。
- **我的阅读**：收藏、离线和参与讨论作为长期阅读资产呈现。
