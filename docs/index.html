更舒服地逛 V2EX。

v2Explore 使用 SwiftUI 原生构建，让首页浏览、长帖阅读、节点关注、搜索与收藏保持同一套清晰节奏，内容始终在前。

原生体验SwiftUI 构建，遵循系统交互

新版界面

内容在前，界面退后一步。

从社区动态到长帖、节点、搜索、收藏与发布，信息层级保持一致；操作则按照 iPhone 的使用习惯重新安排。

日常使用

细节不抢眼，用起来会发现。

没有单独制造一套“高级功能”。每一项能力都服务于更快地找到内容、更轻松地读完，以及以后还能找回来。

01

多种话题流

全部、最热、关注与快捷节点分别记住阅读位置，来回切换不会丢失进度。

02

完整的长帖阅读

支持图片、代码、引用、只看楼主、楼层跳转和长帖分页。

03

收藏与离线

收藏夹、标签和备注都保存在本机，也可以把内容下载后再读。

04

通知与搜索

集中查看回复、@ 和感谢，并通过全文搜索重新找到看过的话题。

05

草稿自动保存

新话题与回复草稿会持续保留，切换页面或暂时退出也不会丢失。

06

凭证留在设备

Token 和网页会话存入 Keychain，不会上传到第三方服务器。

为 iPad 调整

正文与讨论，并肩展开。

宽屏下，话题正文与回复使用双栏布局，各自独立滚动；窗口变窄时再自然回到单栏。
