V2EX · Native Differentiation System

让社区的
“活性”可见。

设计不再模仿论坛网页，也不靠一屏圆角卡片制造“高级感”。系统导航负责原生感，内容层用 Pulse、Orbit、Threadline 三种信息表达建立独有产品身份。

01 / NATIVE

系统负责容器

TabView、NavigationStack、toolbar 与 Search role 保持系统行为；不自绘一个“看起来像 iOS”的壳。

02 / BRAND

内容负责差异

雷达脉冲、节点轨道、讨论脉络都是数据的另一种表达，不是装饰性插画。

03 / GLASS

玻璃只放在功能层

Liquid Glass 仅用于悬浮导航、工具和滚动上下文；正文与列表保持清晰实体表面。

04 / MOTION

动效解释结构

列表到话题采用 zoom transition；玻璃控件通过容器 morph；所有动效服从 Reduce Motion。

SwiftUI implementation language

TabView(role: .search) · tabBarMinimizeBehavior(.onScrollDown) · GlassEffectContainer · glassEffectID · matchedTransitionSource · navigationTransition(.zoom) · scrollTransition · sensoryFeedback · scrollEdgeEffectStyle
