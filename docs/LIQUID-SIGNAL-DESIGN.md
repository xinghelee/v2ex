# Liquid Signal / 液态信号

这一方向建立在 iOS 26 原生 Liquid Glass 之上，但不把玻璃作为内容装饰。玻璃只承担导航、筛选、上下文和临时交互，话题、正文与回复仍使用稳定的实体表面。

## 差异化语言

- **信号带**：首页分类筛选由一组可融合、拆分的玻璃胶囊组成。
- **上下文胶囊**：进入话题后，信号带收束为节点、标题和阅读进度。
- **Threadline**：详情右侧的极窄玻璃轨道表示回复密度、未读位置和楼主楼层。
- **融合回复器**：附件、输入和发送控件在聚焦时合并为一个玻璃容器。
- **节点色场**：节点活跃关系位于实体内容层，色彩透过搜索和筛选玻璃产生轻微折射。

## 原生实现映射

- `TabView` 与系统 toolbar 获取原生 Liquid Glass 外观。
- `GlassEffectContainer` 组织需要融合的筛选和回复控件。
- `glassEffectID` 与 `glassEffectTransition` 支持跨状态形态变化。
- 内容层使用标准材质或不透明表面，保证长文阅读对比度。

## 清晰化版本

第二版移除大面积彩色光晕和细碎信号点，提高正文与分隔线对比度，并将每页玻璃区域限制在顶部上下文、底部导航和一个临时控件内。文字型控件统一采用更稳定的 regular Liquid Glass。
