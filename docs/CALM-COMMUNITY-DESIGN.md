# Calm Community / 安静社区

第三轮设计只借鉴成熟阅读产品的舒适气质，不引入书籍、书架或书城隐喻。产品结构仍然是标准社区论坛。

## 借鉴的体验原则

- 大面积留白与低对比背景。
- 清晰但不夸张的文字层级。
- 主要内容面柔和分组，普通列表减少卡片嵌套。
- 阅读时弱化工具和操作，保持舒适行距。

## V2EX 自有表达

- **社区此刻**：简洁呈现在线人数、新回复和当前热点。
- **讨论进度**：帮助用户阅读和恢复长讨论位置。
- **节点关系**：关注节点使用实用的网格分组，完整目录仍为标准列表。
- **社区足迹**：浏览、收藏、参与和离线内容统一沉淀。
