# Editorial Signal / 编辑信号

这轮重设计以阅读体验为第一优先级：减少通用社交 App 的卡片堆叠，用更接近编辑出版物的排版建立内容层级，并用克制的朱红色表达活跃、未读和讨论进度。

## 核心视觉语言

- 温润纸张底色、近黑正文、单一朱红信号色。
- 首页话题使用左侧编辑索引线，替代厚重卡片和多彩标签。
- 话题详情使用右侧讨论脉络线，承载阅读进度与回复密度。
- 节点页以克制的节点星图作为发现入口，同时保留可预测的列表。
- 个人页命名为“阅读资产”，突出收藏、离线和参与讨论的长期价值。

## 主要页面

1. 今日：首页话题流与社区信号。
2. 问与答：长文阅读、连续回复与讨论脉络。
3. 节点：节点星图与完整节点目录。
4. 阅读资产：收藏、稍后读、离线和阅读节奏。
